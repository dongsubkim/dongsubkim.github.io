# Dong Sub (Dave) Kim — Resume & Portfolio

Public resume at [dongsubkim.github.io](https://dongsubkim.github.io), built with Jekyll and the modern-resume-theme.

## Update the content

Edit `_config.yml` to update the profile, highlights, experience, project case studies, and skills. Keep customer names and internal code names generalized. Publish verified results and distinguish implemented work from production rollouts.

Only publication-ready content belongs in this repository. Work logs, raw exports, supporting evidence, and resume drafts are maintained in a separate private repository.

Project case studies use native `<details>` elements, so readers can expand the implementation details while scanning the main results.

## Run locally

1. Install Ruby 3.1.7 with rbenv.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve`.
4. Open `http://localhost:4000`.

Run `bundle exec jekyll build` to verify the production output. GitHub Pages publishes the root of the `master` branch.
